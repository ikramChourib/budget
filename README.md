# Budget Commun

Application web mobile (installable) pour gérer un budget solo, en couple ou en groupe.

- Dépenses communes (fixes, variables, provisions) et dépenses perso
- Répartition 50/50, au prorata des salaires ou tout en commun
- Un budget par mois, généré à partir du mois précédent
- Export Excel (mois ou tous les mois) et sauvegarde JSON

Les données sont enregistrées dans le navigateur du téléphone (localStorage).
